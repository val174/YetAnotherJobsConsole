# Ещё одна консоль регламентных и фоновых заданий 1С

**Консоль регламентных и фоновых заданий 1С** — ещё одна реализации консоли регламентных и фоновых заданий для 1С Предприятие с поддержкой английского интерфейса.

---

## Основные возможности

### Управление регламентными заданиями

- Просмотр списка всех регламентных заданий в информационной базе
- Просмотр событий в журнале регистрации (используется стандартный журнал регистрации, при открытии устанавливается отбор по пользователю регламентного задания)
- Фильтрация по:
  - объектам метаданных
  - состоянию регламентных заданий (включенные / выключенные / завершенные с ошибкой)
- Включение/выключение заданий (включая пакетные операции)
- Работа с параметрами регламентных заданий (включая параметры типа Структура)
- Расчет даты следующего запуска (выполняется путем перебора дат на ближайший месяц, шаг - 60 секунд)
- Добавление в избранное (в избранное добавляются метаданные регламентного задания, т.о. добавлениие осуществляется для всех экземпляров выбранного задания)

### Мониторинг фоновых заданий

- Просмотр списка фоновых заданий
- Отображение состояния заданий
- Просмотр информации о последних запусках:
  - Дата запуска
  - Состояние
  - Текст ошибки (при наличии)
- Автоматическое обновление списка фоновых заданий

## Использование

### Начало работы

1. Откройте внешнюю обработку в режиме 1С:Предприятие
2. Консоль автоматически загрузит список регламентных заданий из информационной базы
3. Для просмотра списка фоновых заданий перейдите на соответствующую вкладку

### Управление заданиями

- Для редактирования задания дважды щелкните на нем в списке
- Для включения/выключения задания используйте кнопки на панели инструментов или контекстное меню
- Для изменения расписания нажмите на колонку "Расписание"

## Лицензия
